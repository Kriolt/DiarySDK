# Безопасность

## Как сообщить об уязвимости

Сообщайте о ней **приватно** через GitHub Security Advisories репозитория:
вкладка **Security** → **Report a vulnerability**
(<https://github.com/Kriolt/DiarySDK/security/advisories/new>).

Не открывайте публичный issue и не прикладывайте к сообщению настоящие токены,
пароли или данные учеников: достаточно описать, как воспроизвести проблему.

## Поддерживаемые версии

Исправления выходят для последней версии.

## Что мы считаем уязвимостью

- утечка пароля, кода входа, ответа на капчу, токена или ключа потребителя в
  журнал, `repr`, исключение или ответ сервиса;
- обход проверки ключа, разрешений или лимитов сервиса;
- доступ к данным одного ученика по токену другого;
- смешение сессий входа разных пользователей.

## Что учесть при развёртывании

- Файл ключей хранит только хеши; всё равно монтируйте его только для чтения и
  не публикуйте.
- Сервис не терминирует TLS: ставьте его за обратный прокси.
- Токены ученика SDK не хранит; храните их в своём приложении как секреты.
