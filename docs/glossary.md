# Глоссарий

[Документация](index.md) » Глоссарий

## дневник

Электронный дневник «Моя школа» Московской области: сайт
`myschool.mosreg.ru` и его API на `authedu.mosreg.ru`. Источник всех данных
SDK.

## ядро

[`diarysdk.Diary`](library/diarysdk.md#diarysdk.Diary) — часть пакета,
которая сама ходит в дневник. Работает только с российского адреса.

## сервис

HTTP API над ядром: `python -m diarysdk.server`. См.
[справочник сервиса](library/server.md).

## удалённый клиент

[`RemoteDiary`](library/remote.md#diarysdk.remote.RemoteDiary) — клиент
сервиса с тем же интерфейсом, что у ядра.

## потребитель

Программа, которая ходит в сервис со своим ключом: бот, сайт, скрипт. По
имени потребителя считаются лимиты и пишется журнал.

## ключ потребителя

Секрет из заголовка `X-Api-Key`. Сервис хранит только его SHA-256.

## разрешение

Право ключа на особые операции: `login`, `write_profile`,
`acknowledge_journal`. См. [Разрешения ключей](library/server.md#разрешения-ключей).

## токен

JWT дневника, от имени которого идут запросы ученика или родителя. В SDK —
[`Token`](library/token.md#diarysdk.Token).

## ЕСИА, Госуслуги

Единая система идентификации и аутентификации — вход через Госуслуги. Может
попросить капчу и код подтверждения.

## поток входа

Незаконченный вход через Госуслуги, который ждёт кода или капчи:
[`LoginFlow`](library/diarysdk.md#diarysdk.LoginFlow). Живёт 5 минут с
последнего шага.

## MFA, код подтверждения

Второй шаг входа: код из SMS (`sms`), приложения-аутентификатора (`totp`)
или мессенджера MAX (`max`).

## контекст ученика

Идентификаторы ученика в дневнике, которые ядро узнаёт по токену перед первым запросом. Запрашивается один раз на
экземпляр `Student`.

## роль

Кто владелец токена: ученик (`1`) или родитель (`2`). От роли зависит, что
отдаёт дневник; см. [`NotForRole`](library/errors.md#diarysdk.errors.NotForRole).

## учебный год

Период с 1 сентября по 31 августа. В параметре `year` — год его начала:
`2025` — это 2025/26.

## период

Пара `start`, `end` (`datetime.date`, включительно) у методов со списками за
время. Без неё берётся период по умолчанию.

## неизвестный исход записи

Запись ушла, но ответа нет. SDK не повторяет её и бросает
[`WriteUncertain`](library/errors.md#diarysdk.errors.WriteUncertain).

## upstream

Дневник с точки зрения сервиса: «upstream-ошибка» — ошибка дневника, а не
сервиса ([`UpstreamError`](library/errors.md#diarysdk.errors.UpstreamError)).

## пятибалльный средний

`average_five`, `five` и подобные поля — пересчёт самого дневника в
пятибалльную шкалу. SDK своего пересчёта не делает.

## «ознакомлен с дневником»

Еженедельная отметка родителя, которую видят учителя. Отменить её нельзя.
См. [`acknowledge_journal()`](library/diarysdk.md#diarysdk.Parent.acknowledge_journal).
