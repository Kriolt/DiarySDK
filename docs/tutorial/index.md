# Учебник DiarySDK

[Документация](../index.md) » Учебник

Учебник по шагам знакомит с DiarySDK: от первого запроса до своего сервиса.
Главы лучше читать по порядку, но каждая понятна и сама по себе. Примеры
можно копировать и запускать: тесты проекта исполняют их при каждой сборке.

Учебник не описывает каждый метод и каждое поле — это задача
[справочника](../library/index.md). Предполагается, что вы знаете Python и
слышали про `async`/`await`; если нет — вам поможет
[глава про синхронные обёртки](7-service.md#75-синхронный-код).
