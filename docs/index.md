# Документация DiarySDK 0.2.0

DiarySDK — Python-библиотека для школьного дневника «Моя школа» (Московская
область). Она даёт данные ученика по его токену или по токену родителя:
оценки, расписание, домашние задания, рейтинг, учебный план, справки,
настройки, профиль. Ту же библиотеку можно запустить как HTTP-сервис и ходить
в дневник через него.

## Как читать справочник

Сигнатуры записаны так же, как в документации Python:

- *класс* — `diarysdk.Diary(*, hosts=None, ...)`: параметры после `*` передаются
  только по имени;
- *async-метод* — корутина, её нужно ждать через `await`; в
  [`diarysdk.sync`](library/sync.md) у того же метода нет `async`;
- *метод*, *свойство*, *атрибут* — обычные члены класса;
- `start, end : datetime.date | None` — у параметров с `None` по умолчанию есть
  разумное значение, оно описано у метода.

Отметки «*Добавлено в версии 0.2.0*» показывают, с какой версии существует
имя. Имена — английские, пояснения — русские. Даты — `datetime.date`, время —
`datetime.datetime` с часовым поясом; «сегодня» считается по Москве.

> [!IMPORTANT]
> Дневник и Госуслуги отвечают только на запросы с российских IP-адресов.
> Ядро ([`Diary`](library/diarysdk.md#diarysdk.Diary)) и сервис запускайте там,
> откуда дневник доступен. Удалённому клиенту
> ([`RemoteDiary`](library/remote.md#diarysdk.remote.RemoteDiary)) такой адрес
> не нужен: он ходит только в ваш сервис.
